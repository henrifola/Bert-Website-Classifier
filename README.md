# Bert-Website-Classifier
A lightweight website classification tool using BERT to identify the intent and type of a given website based on its textual content.

This project includes a built-in web scraper that extracts text content using BeautifulSoup, performs basic cleaning, and feeds the processed content into a BERT-based model. 
The model uses a simple classifier on top of BERT embeddings to determine the website's category or purpose.
